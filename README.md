# Kuku FM — Promo Finder (Problem 1)

Screenplay-based promo discovery pipeline for **I Married a Broken Soldier. He was a Duke**.

## Approach

1. Parse timestamped screenplay scenes into structured events.
2. Generate continuous 20–60-second promo candidates with post-clip context.
3. Score each candidate for hook (25%), cliffhanger (25%), clarity (25%), emotion (15%), and coherence (10%). Human/Claude-assisted evaluations are recorded as JSON.
4. Apply mandatory quality gates, rank passing candidates, and suppress heavily overlapping clips.
5. Export ranked results and an editorial shortlist. **Video verification remains required.**

## Run

Python 3, no third-party packages required.

```bash
python rank_candidates.py --candidates data/promo_candidates.json --evaluations evaluations --output outputs
```

Supply the original `promo_candidates.json` generated by Phase 2 and all 17 evaluation JSONs in `evaluations/` (one `batch_XX_response.json` per batch). The corrected batch 01 evaluation should be named `batch_01_response.json`.

The full local Phase 4B submission package also includes the 2-page PDF, top-10 showcase, top-20 editorial review and all 162 candidate results. **Those original files are not yet published in this repository.** This repository currently hosts a reproducible ranking component; do not treat it as the complete hosted assignment until the data and deliverables are uploaded.

## Evaluation rules

A clip is eligible only when its decision is PASS, all four quality gates pass, and it has no boundary-cut issue. A payoff appearing in the post-clip lookahead does not automatically invalidate a cliffhanger.

## Limitations

Scores are screenplay-based editorial judgments, not measured engagement. Source video must be checked for actual timing, visual quality, and cliffhanger impact. Do not publish copyrighted screenplay inputs without permission.
